# Paleta oficial — Grupo Tombini

Aplicável ao SGT e à intranet "Nossa Gente". Fonte única de verdade: `packages/design-system/tokens.css`.

| Token | Cor | Uso |
|---|---|---|
| `--gt-green-600` | `#65A70A` | Verde institucional (primária) |
| `--gt-green-700` | `#3F6908` | Verde escuro (hover, estados ativos) |
| `--gt-graphite-800` | `#4F484A` | Grafite institucional (texto, cabeçalho) |
| `--gt-white` | `#FFFFFF` | Branco (superfícies) |
| `--gt-bg` | `#F4F6F2` | Fundo secundário (páginas) |
| `--gt-divider` | `#E5E9E1` | Divisórias, bordas |

## Cores de estado (não oficiais, definidas pelo projeto)

| Token | Cor | Uso |
|---|---|---|
| `--gt-danger` | `#B42318` | Erro |
| `--gt-warning` | `#B54708` | Alerta |
| `--gt-info` | `#175CD3` | Informação |
| `--gt-success` | `#067647` | Sucesso |

Essas cores de estado não foram fornecidas como oficiais; são escolhas do projeto para garantir contraste e acessibilidade. Se o Grupo Tombini definir cores oficiais para estados, elas substituem estas.

## Aplicação

- SGT: usa todos os tokens.
- Intranet: usa os mesmos tokens; não tem paleta própria.
- Documentos impressos: usam os mesmos tokens, com ajustes de contraste para papel.

## O que não foi feito

- Nenhum manual de marca formal foi recebido além dos códigos HEX fornecidos.
- Nenhuma validação de contraste WCAG foi executada (a ser feita na fase de testes).
